Multi-factor authentication for WordPress sign-in: authenticator apps, SMS, WhatsApp and voice through Twilio Verify or Plivo Verify, email codes, backup codes and trusted browsers.

== Description ==

Potomac MFA adds a verification step to WordPress sign-in. After the correct password is entered, no session is issued until the user enters a code from one of their enrolled methods.

* Authenticator apps (TOTP), verified on the site with no per-use cost.
* SMS, WhatsApp and voice codes through Twilio Verify or Plivo Verify, selectable per site.
* Email codes generated by the site and sent with wp_mail(), with no provider fee.
* Single-use backup codes and optional trusted browsers.
* Role-based enforcement with a setup period.
* Rate limiting, lockouts and an audit log.
* Controls for application passwords and XML-RPC, which otherwise bypass two-factor authentication.
* Configuration import and export, and WP-CLI commands, for fast setup across many sites.

Developed by [Potomac Technologies, LLC](https://potomactech.net). Source and documentation: https://github.com/rosspotomactech/potomac-mfa

== External services ==

When SMS, WhatsApp or voice methods are enabled, the site sends the recipient's phone number and the delivery channel to the selected provider to deliver and check a code:

* Twilio Verify (verify.twilio.com). Terms: https://www.twilio.com/legal/tos. Privacy: https://www.twilio.com/legal/privacy
* Plivo Verify (api.plivo.com). Terms: https://www.plivo.com/legal/tos/. Privacy: https://www.plivo.com/legal/privacy/

Update checks query the GitHub REST API (api.github.com) for the latest release of the configured repository. No site or user data is sent.

== Installation ==

1. Download potomac-mfa.zip from the latest GitHub release and upload it under Plugins → Add New → Upload Plugin.
2. Activate the plugin.
3. Configure Settings → Potomac MFA, or import a configuration file under Import and export.
4. Set up two-factor authentication on your own account under Users → Two-Factor before requiring it for administrators.

== Frequently Asked Questions ==

= How do I regain access if I lose my phone? =

Use a backup code. Otherwise another administrator can reset your two-factor authentication from the Users screen, the WP-CLI command `wp pmfa reset-user <user>` resets it, or `define( 'PMFA_DISABLE', true );` in wp-config.php suspends the plugin.
